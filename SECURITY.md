# EU Age Verification White Label Solution Vulnerability Disclosure Policy (VDP)

## Guidelines

If you find an **accidental** vulnerability or security issue, please contact the developer privately in order to coordinate the publishing of a security update followed by a responsible disclosure later when enough systems are patched.

If you find a **deliberate** vulnerability or backdoor, then please immediately and deliberately leak all the details publicly and publicly shame the developer for having deliberately introduced a backdoor in their software, product or algorithm, and make sure to release all the PoC, documentation and ready-made exploitation tools publicly and for free.
